# 🎬✨ Error404rt Anixart Patches

**Смотрите аниме без рекламы и отвлекающих факторов.** 🍿

Набор патчей для **Anixart**, созданный на базе Morphe Patcher. Цель проекта — убрать рекламные элементы приложения, не нарушая основные функции приложения и воспроизведение видео.

## 🛡️ Что предоставляет патч

### 🚫 Remove ads
Отключает рекламные форматы Anixart:

- 🧹 **Баннерная реклама** — удаление нижнего рекламного баннера и подписи «Реклама».
- ⛔ **Межстраничная реклама** — блокировка рекламных показов между экранами.
- ▶️ **Реклама перед Kodik** — пропуск рекламного преролла перед началом просмотра.

Каждая настройка доступна отдельно — можно управлять всеми тремя вариантами рекламы независимо.

## 📱 Совместимость

- Приложение: **Anixart**
- Патчер: **Morphe Patcher**
- Формат сборки: **`.mpp`**

Поддерживаемые версии Anixart будут указаны после проверки APK и успешной сборки патча.

## 📦 Установка

1. Установите Morphe Manager.
2. Добавьте источник патчей проекта в Morphe Manager.
3. Выберите **Error404rt Anixart Patches**.
4. Примените **Remove ads** к поддерживаемой версии Anixart.

> Используйте совместимый оригинальный APK. Перед применением рекомендуется сохранить резервную копию приложения и его данных.

## ⚙️ Сборка

Проект использует GitHub Actions и Morphe Patches Template. Готовый файл `.mpp` формируется автоматически и публикуется в GitHub Releases после успешной проверки.

Для локальной сборки:

```bash
./gradlew buildAndroid
```

Результат: `patches/build/libs/patches-*.mpp`.
